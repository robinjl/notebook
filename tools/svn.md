## 常用命令

| 功能                              | 命令                                                                          |
| --------------------------------- | ----------------------------------------------------------------------------- |
| 将本地已有项目连接到远程 SVN 仓库 | `svn checkout <远程仓库URL> --force .`                                        |
| 查看仓库信息                      | `svn info`                                                                    |
| 更改仓库地址                      | `svn relocate <新仓库URL>`                                                    |
| 从版本库删除（但保留本地文件）    | `svn delete --keep-local <文件名>`                                            |
| 忽略文件增加到版本库              | `svn add --depth=empty <文件名>`                                              |
| 提交本地变更到版本库              | `svn commit -m "提交信息"` （VS Code SVN 插件上传多个文件无效时，执行命令行） |
| 忽略文件                          | `svn propset svn:ignore <文件名>`                                             |
